# SHARK STUDIES / 鲨鱼习作

五张用户原图构成的响应式 Fabrication 作品集。无构建步骤，无安装依赖。

## 运行

直接打开 `dist/index.html` 即可浏览。也可在 dist 文件夹启动任意静态网页服务器。

## 编辑

- 页面右上角「编辑文字」：点击带虚线的标题或段落即可修改，「完成」退出编辑。
- 修改自动保存在当前浏览器。不会自动同步至已发布站点或其他设备。
- 编辑工具栏「导出文案」保存 JSON；「导入文案」可在其他浏览器恢复。
- 永久修改源文件：在 `dist/index.html` 中编辑对应文字，`style.css` 管理布局，`script.js` 管理交互。修改源文件后重新部署即可对访问者生效。浏览器已存的文案优先显示，可清除此站点的浏览器存储后查看源文件更新。
- 图片位于 `dist/assets/`，五张均为原始 PNG，未重绘、滤镜处理或压缩。替换同名文件即可更换素材。

## 包含功能

非对称项目布局、中英双语文案、五项作品索引、图片原图放大、滚动渐显、顶部阅读进度、手机适配、键盘与减少动画偏好支持。

文案按图片可见信息拟写，作品标题可自行调整；未把具体工具、尺寸或性能当作已知事实。第四、第五项为静态照片展示，无真实装置运行演示。

Google Fonts 在线字体不可用时，页面自动使用本机字体。离线打开仍可浏览全部作品和使用编辑、放大功能。
